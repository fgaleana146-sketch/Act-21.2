# 🛡️ Práctica de Ciberseguridad: Lógica de Detección en Python

Este repositorio contiene la implementación práctica de un algoritmo básico de ciberseguridad para la detección de amenazas digitales mediante análisis de texto en Python.

---

## 🎯 Objetivos de la Práctica
* Comprender la diferencia conceptual y operativa entre las amenazas digitales y sus mecanismos de detección.
* Analizar cadenas de texto y aplicar lógica condicional en Python para la toma de decisiones.
* Documentar y versionar el código utilizando Git y GitHub.

---

## 📁 Contenido del Repositorio

Dependiendo del ejercicio, este repositorio incluye uno de los siguientes módulos:

1. **anti_phishing.py**: Simulador de análisis de URLs mediante reglas heurísticas para la detección de phishing.
2. **filtro_antispam.py**: Filtro de mensajes basado en listas negras (*blacklists*) de palabras clave de spam.

---

## ▶️ Cómo ejecutarlo

1. Copia el archivo `.py` en el compilador de Python.
2. Ejecuta el programa.
3. Observa la clasificación en consola: SEGURO / ALERTA PHISHING o CORREO LIMPIO / SPAM DETECTADO.
